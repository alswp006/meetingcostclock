# MeetingCostClock

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
참석자 수와 평균 급여를 입력하면 회의가 진행되는 동안 실시간으로 누적 비용을 보여주는 직장인용 회의비용 계산기

## Problem
많은 직장인이 불필요하게 길어지는 회의로 인한 시간·인건비 낭비를 체감하지 못한 채 습관적으로 회의를 반복한다. 회의 비효율을 수치로 보여줄 도구가 없다.

## Target Users
스타트업·중소기업 직장인, 팀장/PM 등 회의를 자주 주관하는 2030-40대 사무직

## Core Features
1. 참석자 수+평균 연봉 입력 시 시급 자동 환산
2. 회의 진행 중 실시간 누적 비용 타이머 표시
3. 회의 종료 후 총 비용/낭비 추정 리포트
4. 회의 비용 히스토리 및 팀 랭킹 저장
5. 리포트 공유용 요약 카드 이미지 생성
6. 회의 없는 날 챌린지 배지 시스템

## Monetization
- Model: ads
- Estimated MRR: ₩450,000~550,000
- Reasoning: 회의 종료 리포트 및 공유 카드 생성을 리워드 광고로 게이팅하면 회의가 잦은 직장인 특성상 주 여러 회 재방문이 가능하다. 배너 광고는 타이머 화면 하단에 자연스럽게 배치 가능.
